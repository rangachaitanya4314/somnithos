# SOMNITHOS
> *Where dreams meet meaning.*

Somnithos is an evidence-first nocturnal consciousness engine and artistic dream synthesis platform. It bridges the gap between historical scholarship, cognitive sleep neuroscience, and original creative imagination.

---

## The Two-Layer Architecture

Somnithos operates on an uncompromising separation between documented facts and creative interpretation:

1. **The Evidence Layer**:
   - **Documented Historical Traditions**: Grounded strictly in authenticated primary manuscripts (e.g. *Papyrus Chester Beatty III*, Artemidorus' *Oneirocritica*, *Brihadaranyaka Upanishad*, *Iškar Zaqīqu*, *Zhougong Jiemeng*, *Talmud Berakhot*, *Sarashina Nikki*, *Kitāb al-'Ibārah*).
   - **Cognitive Sleep Neuroscience**: Rigorously cataloged empirical findings and theoretical models (e.g. *Threat Simulation Theory*, *Sleep-Dependent Affect Regulation*, *Memory Consolidation*, *Continuity Hypothesis*).
   - **Epistemic Standards & Badges**: Standardized classifications (`HIGH`, `MODERATE`, `HISTORICAL`, `TRADITIONAL`) and a transparent **"No Reliable Source Found"** fallback when motifs lack academic evidence.

2. **The Imagination Layer**:
   - **Original Creative Reflections**: Evocative personal perspectives and poetic thoughts explicitly labeled as original AI reflections inspired by the dream narrative.
   - **Faithful Generative Dream Artwork**: Multi-entity feature extraction that visualizes concrete dream elements (vehicles, creatures, architecture, lighting, color palettes) via a modular engine with both client-side procedural canvas and external generative AI provider support.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Test Suite (Provenance & Artwork Verification)
```bash
npx tsx src/test_pipeline.ts
```
